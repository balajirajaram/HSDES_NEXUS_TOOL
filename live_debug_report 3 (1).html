Hang — UPI Topology Convergence Failure

Root cause: After programming Cpu0P0KtiPortDisable=1 / Cpu0P2KtiPortDisable=1 and a cold/PowerGood reset, BIOS's UPI Reference Code (UPIRC) hangs during early SBSP minimum-path topology tree construction ("CPU0 Link Exchange" / LEP peer discovery) — before it ever reaches the documented "Check for KTI Topology Degradation" handler. The peer socket's Link-Exchange-Peer (LEP) state is not correctly invalidated/reconciled after the asymmetric socket-0 port disable, so BIOS never converges on a valid 2S-degraded topology and the platform collapses into an unbootable degenerate state (enumerated as "1S0Q") with the entire Socket-0 UPI fabric left un-trained.

Phase LD-5 — Final Root Cause (GENI synthesis, confidence 0.88)

Evidence Chain

Baseline: full 2S6Q, all links Fast Mode 24GT/s, symmetric registers — proves platform/wiring healthy pre-degrade.
↓
Cpu0P0/P2 KtiPortDisable=1 applied → cold/PowerGood reset (not warm) — rules out warm-reset credit hypothesis per BIOS FAS.
↓
Serial log hangs mid "CPU0 Link Exchange"/LEP discovery, before reaching "Check for KTI Topology Degradation" — failure is in early topology construction, not later routing/credit phases.
↓
Post-hang: system enumerates as degenerate "1S0Q"; ALL Socket-0 UPI ports (not just the 2 disabled) stuck in ResetC — BIOS never converged on any valid 2S-degraded topology.
↓
Asymmetric bios_kti_err_st / error-mask state between sockets — peer LEP/topology data not reconciled after the one-sided port disable.

Recommended Fix

Update BIOS/UPIRC so that when a socket-local UPI port disable is applied, the corresponding peer LEP/link entries are invalidated before SBSP minimum-path topology construction, then follow the documented GNR AP 2S degrade flow: try 2S-6L → 2S-4L (mapping out the correct UPI pair) → only fall back to 1S if no valid 2S topology exists. IpUpiGetStatus/LEP collection must not stall indefinitely waiting on inconsistent peer state.

Next Debug Step

Test whether explicitly invalidating peer-side LEPs (or disabling the paired peer link) allows convergence to a valid 2S4L topology.
