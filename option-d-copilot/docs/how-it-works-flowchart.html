Auto HSD Analyser — How It Works

Copilot-native HSD triage & debug assistant for Intel GNR / SRF / CWF

An engineer enters an HSD ID plus a few symptom words, and Copilot returns likely root cause and the exact next-step debug commands — running locally with each engineer's own Intel access. No server, no shared token.
