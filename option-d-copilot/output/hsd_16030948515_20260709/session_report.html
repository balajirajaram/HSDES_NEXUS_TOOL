🔍 Leading Root-Cause Hypothesis (not yet confirmed on this unit)

Statement

The degradation topology disables a UPI link that must remain always-enabled — most likely UPI0, or it leaves a socket with no active link. On GNR, UPI0 disable is a DFx-only knob and production BIOS does not support it, so the fabric fails to train and the system hangs at boot.

Evidence Chain

  • KBExact symptom signature match in learning KB (entry ed28650a).
  • HSDESHSD 16024158116 (GNR-AP B0): boot hang PC 0xA3 when UPI stack disabled via BIOS knobs — fixed by keeping ≥1 UPI link active.
  • HSDES16025091446 shows UPI PHY DRIFT BUFFER ALARM on the same knob family.

Candidate Fix / Workaround

Fix: Ensure the degradation config never disables UPI0 and always leaves ≥1 active UPI link per socket.

Workaround: Re-run degradation with only non-UPI0 links disabled; validate topology before cold reboot.

Reference: HSD 16024158116; tracking 14020755652 (lift UPI0 "always-enabled" restriction).
